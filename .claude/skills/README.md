# Project skills

Claude Code project skills live under:

```text
.claude/skills/<skill-name>/SKILL.md
```

Current external skills:

```text
javascript-pro
test-master
```

To refresh the selected skills from the configured third-party repository, run from the project root:

```powershell
.\scripts\install-claude-skills.ps1
```

Review third-party skill content before committing updates.

Project-specific rules in `CLAUDE.md` and the current repository architecture always override generic skill guidance.
