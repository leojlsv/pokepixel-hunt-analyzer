# Project skills

Project skills live under:

```text
.claude/skills/<skill-name>/SKILL.md
```

Start with the external skills:

```text
javascript-pro
test-master
```

The directories are committed with `.gitkeep` only so the intended structure appears in Git.

To install the selected skills from the Jeffallan/claude-skills repository, run from the repository root:

```powershell
.\scripts\install-claude-skills.ps1
```

Review third-party skill content before committing it.
Project instructions and actual repository architecture override generic skill preferences.
