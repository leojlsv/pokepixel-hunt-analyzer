# Security

## Supported version

Security fixes target the latest released version of PokePixel Hunt Analyzer.

## Reporting

Do not publish credentials, tokens, cookies, authenticated WebSocket URLs or private/raw traffic captures in Issues, Discussions or Pull Requests.

For a suspected security vulnerability, prefer GitHub's private vulnerability reporting / Security Advisory flow when it is available for this repository.

If the problem is a normal functional bug and contains no sensitive data, use the Bug Report template.

## Project security boundary

The Analyzer is designed to observe inbound PokePixel events passively. Changes that send, replay or modify gameplay traffic are outside the supported architecture and require an explicit project decision.
